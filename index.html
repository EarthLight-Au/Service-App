Setup — Azure App Registration
1
Register an app in Azure Portal
Go to portal.azure.com → Azure Active Directory → App registrations → New registration. Name it "EarthLight Audit Tool". Set the redirect URI to Single-page application (SPA) and paste the URL of this page (your GitHub Pages URL once deployed).
2
Copy your Application (client) ID
After creating the app, copy the Application (client) ID from the overview page. Paste it into the field below and save.
3
Grant API permissions
In the app → API permissions → Add Microsoft Graph → Delegated → Files.ReadWrite and User.Read. Click "Grant admin consent".
4
Sign in below
Paste your Client ID, hit Save, then Sign in. Visits will auto-upload to OneDrive/EarthLight Audits/ as PDF + JSON files each time you submit — one pair of files per visit, covering every tower on it.

EmailJS — send from the app

One-time free setup at emailjs.com lets the Email button send the PDF straight from the app — no mail app, no manual attach step. Full steps are on the "How it works" tab.

Free EmailJS plan: ~200 emails/month, attachments capped around 50KB — so the emailed PDF leaves photos out (they're listed by count instead). The full report with photos still goes to OneDrive automatically, or download it manually. On the $9/mo Personal plan raise the cap to ~450KB.

What works offline

Once this page has loaded once, everything works with no signal at all: filling in a visit, adding towers, adding parts from the price book, saving, totals, GPS entry, PDF generation. Everything is held in this browser's local storage, and the app itself is cached on the device (via its service worker) so it opens with zero bars of signal — not just while the tab happens to still be open. Nothing leaves the device until you trigger it (Email, or an automatic OneDrive sync once you're back in range).

Installing it like an app

On mobile (iOS/Android), open this page in Safari or Chrome and use Add to Home Screen — it installs properly (icon, splash screen, no browser address bar) because the page ships a manifest + offline service worker. On desktop, use the install icon in Chrome's address bar. Install it once while you still have signal; after that it's yours to use anywhere.

Multiple towers on one report

A "Visit" is one site call-out and can hold several towers. Use + Add tower under the visit details to add another — each tower gets its own Tower Details, Condition, Findings, Parts & Cost and Photos, switchable via the tower tabs. Tap Report to generate one combined PDF covering every tower on the visit, each on its own page, with a visit summary and grand total up front.

PDF report

Tap Report at the bottom to preview, then Download PDF to save a properly formatted EarthLight Site Service Report — with every tower on the visit — to your device. This is the full file (with photos) that gets uploaded to OneDrive.

Emailing the report (EmailJS setup)

The Email button sends the report itself, from inside the app, with the PDF attached — no mail app hand-off. It uses EmailJS, a free service that lets a web page send email without its own server. One-time setup:

1
Create a free EmailJS account
Sign up at emailjs.com, then under Email Services connect the mailbox you want reports to send from (Gmail, Outlook, or your own SMTP).
2
Create an email template
Under Email Templates, make a template with a {{message}} body variable for the text summary. Then open the Attachments tab on the template and add a Variable Attachment: filename {{pdf_filename}}, content type PDF, parameter name pdf_base64.
3
Grab your IDs
Copy the Service ID and Template ID from their respective tabs, and the Public Key from Account → General.
4
Paste into Price Book & Send-to → EmailJS
Save it there. From then on, Email sends immediately with the PDF attached. Free plan caps attachments around 50KB, so the emailed PDF leaves out photos (it lists how many were taken) — the full photo report is still in OneDrive or the manual download.

OneDrive auto-upload

Set up your Azure client ID under the OneDrive tab, sign in once with your Microsoft work account, and every subsequent visit submission automatically uploads a full PDF + JSON (photos included, every tower included) to OneDrive / EarthLight Audits / in the background — as soon as you have signal. Visits submitted offline are queued and uploaded the moment connectivity returns. This is the permanent record for the whole team, for years to come.

Price book

The Price Book tab is the single source of truth for every part code, default quantity and price in the picker. Edit a price there and it's live everywhere immediately. Import a .json export from another device, or a plain .csv straight from a spreadsheet price list (columns: category, code, description, qty, price). Export after changes and share the file with other technicians — each device imports it independently.
